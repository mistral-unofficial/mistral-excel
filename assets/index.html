Mistral for Excel

An Excel add-in that lets Mistral read, analyse and edit your workbooks.

Download manifest

Install for yourself

  1. Excel on the web: Home → Add-ins → More add-ins → My add-ins → Upload my add-in, then choose the downloaded manifest.
  2. Excel for Mac: copy the manifest into ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/ (create the folder if needed) and restart Excel. The add-in appears under Home → Add-ins → My Add-ins.
  3. Excel for Windows: put the manifest in a shared network folder, add that folder under File → Options → Trust Center → Trusted Add-in Catalogs, restart Excel and pick it under Add-ins → Shared Folder.

Install for your organisation

A Microsoft 365 admin can upload the manifest under Admin center → Settings → Integrated apps → Upload custom apps and assign it to users or groups. It then appears for them automatically.

First start

Open Home → Mistral, click ⚙ and paste your own API key from console.mistral.ai/api-keys. The key stays on your machine; requests go directly to the Mistral API.
